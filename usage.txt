1. to run script at cmd line:

python 3_build_demo_dbs_in_snwflk.py

2. to output to a logfile

python3 -u 3_build_demo_dbs_in_snwflk.py >> build_demo_dbs_log_103126_1228.txt 2>&1

python3 -u 3_build_demo_dbs_in_snwflk.py > logs/3_build_demo_dbs_in_snwflk_log_$(date +%m%d%y_%H%M).txt 2>&1

3. to describe DBs you'd like the agent to build:

To choose which databases get built, edit the request text inside run_agent(...) at the bottom of build_demo_dbs.py, under if __name__ == "__main__":.

Write it in plain English, for example: run_agent("Build three demo databases: sales, retail, and log_processing.")

The prefix demo_oct_31_ is added automatically, so you get names like DEMO_OCT_31_SALES.

4. to run eval script 

python3 -u eval_dbs.py > logs/eval_dbs_log_$(date +%m%d%y_%H%M).txt 2>&1
